HOW TO ADD A POEM
-----------------
Everything above the first "@title:" line is ignored, so these notes stay private.

To publish a new poem, copy a block below and change the words:

    @title: Your poem title
    @date: ජනවාරි 28, 2026
    First line of the poem.
    Second line.

    A blank line makes a stanza break – it is kept exactly as you type it.

Rules:
  - "@title:" starts a new poem (this is required).
  - "@track:" is optional – name a song and the page gets a play button.
  - "@date:" sets the order. The book reads oldest first, so where a poem sits
    in this file does not matter – put new ones anywhere. Sinhala or English
    month names both work, and so does a plain 2026/08/16. Undated poems go last.
  - Save the file, commit, and it appears on the Journal page automatically.

There is one book, කවිය, and every poem here goes in it.

These poems came from මගේ කවි පොත.docx, which sits beside this file.
That document is the source; this one is what the site reads.
